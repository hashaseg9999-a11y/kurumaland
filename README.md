# KurumaLand

## 種別

アプリ開発プロジェクト

## 目的

1歳8ヶ月の幼児向け・車テーマの知育PWA。色・形・大小の認知と手先の操作(微細運動)を育てる。
日本語・英語・タイ語の3言語音声対応。iPad Safari(ホーム画面追加)で全画面・オフライン動作。

## 状態

6種類のアクティビティ、3言語音声、保護者向け設定、おしまいタイマーを実装済み。
`main` に反映されるとGitHub Actionsがビルドし、GitHub Pagesへ公開する。

公開URL: `https://hashaseg9999-a11y.github.io/kurumaland/`

## 技術スタック

- Vite + TypeScript(Vanilla TS、フレームワークなし)
- PWA(vite-plugin-pwa)/ GitHub Pages 配信
- 画像素材: NANOBANANA 生成(透過WebP)
- 音声: Web Speech API(ja / en / th)

## 設計ドキュメント

実装前に必ず [docs/DESIGN.md](docs/DESIGN.md) を読むこと。全イシュー共通の契約(Activityインターフェース、音声API、素材命名規約、非ドーパミン設計原則)が定義されている。

## 起動方法

```powershell
npm install
npm run dev
```

ターミナルに表示されるURLをブラウザで開く。iPadから確認する場合は、開発PCと同じネットワークに接続し、Network欄のURLをSafariで開く。

## 遊び方

絵をタップして、次の6種類から遊びを選ぶ。

- しんごうでGO
- いろのしゃこ
- おおきい・ちいさい
- みちをなぞろう
- くるまあらい
- くるまパズル

画面左上の家ボタンで、いつでも遊びの選択画面に戻れる。

## 言語とおしまいタイマー

1. 画面右上の歯車を3秒間長押しする。
2. 日本語・英語・タイ語・順番のいずれかを選ぶ。
3. 必要に応じて、おしまいタイマーを「なし・10分・20分・30分」から選ぶ。
4. 音声は「テスト発話」で確認し、「閉じる」で遊びに戻る。

「順番」は、発話するたびに日本語→英語→タイ語の順で切り替わる。タイ語音声が端末にない場合は、エラーを出さず無音で遊びを続ける。

タイマーの時間が来ても遊びの途中では止まらず、次の課題が終わってから車が車庫へ戻り、「おしまい」画面になる。再開は右上の歯車を3秒長押しし、保護者向け設定の「遊びを再開」を押す。

## iPad Safariでの使い方

1. SafariでKurumaLandを開く。
2. 共有ボタンから「ホーム画面に追加」を選ぶ。
3. ホーム画面のアイコンから起動し、iPadを横向きにする。
4. 最初に画面を1回タップして音声を有効にする。

縦向きでは「よこにしてね」画面を表示する。一度オンラインで開いて読み込みが完了した後は、ホーム画面のアイコンからオフラインでも起動できる。

## GitHub Pagesへの公開

`main` ブランチが更新されると、`.github/workflows/deploy.yml` が次を自動実行する。

1. `npm ci`
2. `npm run build`
3. `dist` をGitHub Pagesへ公開

初回のみ、GitHubリポジトリの「Settings」→「Pages」→「Build and deployment」で、Sourceを「GitHub Actions」に設定する。

## ガイドアクセスの設定

ホームバー等の誤操作を防ぐため、iPadのガイドアクセスを利用する。

1. iPadの「設定」→「アクセシビリティ」→「ガイドアクセス」を開き、有効にする。
2. パスコード設定で、終了時に使うパスコードまたはFace ID / Touch IDを設定する。
3. KurumaLandを開き、トップボタンまたはホームボタンを3回押す。
4. 必要なオプションを確認して「開始」を押す。
5. 終了時は同じボタンを3回押し、設定した方法で解除する。
